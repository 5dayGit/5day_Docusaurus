### **Connect Claude AI with 5day.io**

After Claude AI is enabled at the tenant level, users can connect their Anthropic account from My Settings using an Anthropic API key. 
 
You can get your API key from the Anthropic Console. Copy the API key and paste it into the API key field in 5day.io. 

To connect Claude AI: 
- Log in to 5day.io. 
- Click on your Profile icon. 
- Go to My Settings. 
- Click Integration Center. 
- Click the Claude AI card. 
- Enter your Anthropic API Key. 
- Click Connect. 

You can get your API key from your Anthropic account. Copy the API key and paste it into the API key field in 5day.io. 

Once connected: 

Your Claude AI connection will be displayed as connected. 

5day.io can use Claude AI for content generation and other supported AI workflows. 

Claude AI can use relevant context from your projects, tasks, and ongoing marketing work to generate more relevant content. 

Marketing teams can use the integration to create and refine content without manually copying project and task information into an AI tool. 

A Disconnect button will be available. 

To disconnect Claude AI, go to My Settings → Integration Center → Click the Claude AI card and click Disconnect. 

Note: You must have the required permissions to connect Claude AI. If the integration is disabled at the account level or restricted by your role, the option will appear in a disabled state. Your Anthropic API usage and any associated charges are managed through your Anthropic account.
